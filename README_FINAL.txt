DinoWorld — Final Project
Developer: Askar Alibek | Group: SE-2515

Open index.html using VS Code Live Server. Internet required for Bootstrap/jQuery CDN and GBIF live API.

Pages: Home, Dinosaurs, Timeline, Gallery, About, Museum, Discovery Lab, Account, Profile.

NEW FINAL FEATURES:
- Account: Sign Up / Log In with JavaScript validation, phone validation, password complexity and localStorage demonstration. Account data is kept only in this browser, and session state uses sessionStorage. This is NOT secure real-world authentication; do not enter a real password.
- Profile: show stored name/email/phone; log out or delete the demo account.
- Discovery Lab: real GBIF public API via fetch(), loading, timeout and error states. Separate original dinosaur runner mini-game (NOT an API).
- Museum: contact form with email, required-field and phone validation; original registration demo removed to avoid duplicate forms.
- Existing six-assignment functionality, sounds, jQuery, dark mode and images retained.

IMPORTANT: Before submission, publish this folder to GitHub Pages and test every page, links, images and API on desktop/tablet/mobile. Hosting and browser testing cannot be completed by the ZIP itself. Submit ZIP, PDF report and TXT with repo/live links per the course rules.

3D Fossil Museum: Discovery Lab includes original interactive Three.js reconstructions (not Smithsonian scans), rotation/zoom/specimen selection. Three.js loads from jsDelivr and requires internet. The GBIF live API lookup remains the external API integration.
